# 成绩查询页

学生输入「姓名 + 查询码」（或「姓名 + 身份证号」）查看自己的成绩（含小分）。纯静态网页，可以用 GitHub Pages 免费发布。

> 现在的 `data.json` 是高一5班这次数学考试的真实小分（已加密），凭证是「姓名 + 身份证号」，目前收录 36 人。
> 董泽宸、张思清尚未提供身份证号，暂时查不到；补齐后在表里加上这两行重新生成即可。
> 生成工具规则：表里有「身份证号」列就用身份证号；只有「查询码」列就用已有的码；两列都没有就自动生成新码并下载名单。

## 文件

| 文件 | 作用 | 要不要上传 |
|---|---|---|
| `index.html` | 学生用的查询页 | 要 |
| `lib.js` | 加密 / 解密逻辑 | 要 |
| `data.json` | **加密后**的成绩数据（现在是两个虚构学生的示例） | 要，每次考试替换 |
| `tools/make-data.html` | 老师本地生成 `data.json` 的工具 | 可以一起传，里面不含数据 |

**原始成绩表（Excel / CSV / PDF）千万不要放进这个文件夹或上传到 GitHub。** `.gitignore` 已经挡掉了常见格式，但仍请留意。

## 每次考试怎么更新

1. 用浏览器打开 `tools/make-data.html`（发布后也可以访问 `https://你的用户名.github.io/仓库名/tools/make-data.html`，全程本地计算，不上传）。
2. 在 Excel 里复制整张表（表头要有「姓名」「身份证号」），粘贴进去 → 读取表格。
   - 可选：加一行姓名写「满分」、身份证号空着，查询页会显示每题满分，丢分的题标红。
   - 身份证号列在 Excel 里要设成「文本」格式，否则末几位会变 0，工具会提示哪些行有问题。
3. 勾选要给学生看的列（排名、学号默认不勾）→ 生成 → 得到 `data.json`。
4. 在 GitHub 仓库页面上传这个 `data.json`，覆盖旧的，1～2 分钟后生效。
5. 用一两个真实学生试查一下。

## 第一次发布到 GitHub Pages

1. 登录 github.com → 右上角 **+** → **New repository**，名字随便起（比如 `score`），选 **Public**（免费账号的 Pages 只能用公开仓库）。
2. 进入仓库 → **Add file → Upload files**，把 `index.html`、`lib.js`、`data.json`、`tools` 文件夹、`.gitignore` 拖进去 → **Commit changes**。
3. 仓库 **Settings → Pages** → Source 选 **Deploy from a branch**，Branch 选 `main` / `/(root)` → Save。
4. 等一两分钟，页面顶部会出现网址：`https://你的用户名.github.io/score/`，发给学生即可。

## 安全性说明（请务必看）

- `data.json` 里没有明文姓名、身份证号或分数。每个学生一条记录，用「姓名+身份证号」派生出的密钥单独加密（PBKDF2-SHA256 60 万轮 + AES-GCM），只有输对两项才能解开自己那一条。
- **但它不是绝对安全的。** 身份证号的组合其实不多（地区码、出生日期大致可猜），如果有人知道某个学生的姓名、并且愿意用高性能显卡花一段时间逐个去试，理论上能试出来。60 万轮的作用是把这件事变得很慢、很费劲，不是让它不可能。
- 仓库是公开的，**旧版本的 `data.json` 会一直留在 Git 历史里**，覆盖上传并不能删掉它。
- 因此建议：
  - 只放分数，不放排名；
  - 成绩不再需要查询时，直接删除整个仓库（Settings 最下方 Delete this repository），而不是只删文件；
  - 发布前按学校关于成绩公布、学生个人信息的规定确认一下是否允许。
