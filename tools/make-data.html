生成加密成绩数据（老师本地用）

全程在本机浏览器里完成，不联网上传。生成的 data.json 里没有任何明文姓名、身份证号或分数。
一个 data.json 可以放多张表（比如「期中各科成绩」「期中数学小分」），学生查一次就能切换着看。

1. 新建，还是往已有数据里追加一张表？

追加：选择网站里现在的 data.json（可从 GitHub 仓库下载）。同名的表会被替换，其他表保留。
新建：不用选，直接往下填。

2. 名称

3. 粘贴成绩表

在 Excel / WPS 里选中整张表（含表头）复制，粘贴到下面；也可以选一个 CSV 文件。
表头要有 姓名，以及 身份证号 或 查询码 其中一列；两列都没有就自动生成查询码。
可选：加一行姓名写 满分，查询页会显示每项满分、丢分标红。「等第」列会显示成前一科旁边的小标签。

4. 选择要给学生看的列

身份证号永远不会写进数据。学籍号、学号、排名类的列默认不勾选。
